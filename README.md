# Fieldsheet

A mobile-first prototype for real estate agents to build a property listing on-site, starting with the address and core listing facts.

Currently a static, single-page app (`index.html`) with no backend — data is stored in the browser via localStorage. Login is a placeholder for testing; address autocomplete uses a small local demo dataset until a real provider (Google Places, Mapbox, Smarty, etc.) is wired in.
